# «Проверь» — все роботы сразу (владелец, 20.11.2026)

Владелец: «если я говорю проверь — это сейчас задействовать всех ботов разного характера». Не спрашивать, не ждать — запускать.

## 1. Подготовка
- `git pull --rebase`, прочитать `docs/SYNC.md` (правила, «Сообщения»).
- Тема = слова после «проверь». Нет темы → весь сайт.

## 2. Запуск — ОДНИМ коммитом в `main`, строка `<дата> <тема>` в каждый файл
| Робот | Файл-команда | Что делает | Результат |
|---|---|---|---|
| Рой (20 роботов) | `.github/qa.txt` — строка должна содержать `swarm`; для языков добавить `языки` | все страницы, кнопки, звук, ссылки, ПК/телефон/A31 | `qa/latest/report.md` в main |
| Кликер (6 роботов) | `.github/click.txt`; для языков — со словом `языки` | ПК/планшет/телефон: каждая кнопка + снимок, каждая ссылка — открывается ли и совпадает ли по смыслу | ветка `shots-click`, `report.md` |
| Языки | `.github/lang.txt` | lang, hreflang, переключатель языка, что осталось по-английски, меню без перевода | ветка `shots-lang`, `report.md` |
| Фотограф | `.github/photo.txt` | весь сайт, меню, каждая кнопка (ПК + телефон) | ветка `shots` |
| Главная | `.github/home-look.txt` | слайдер на 5 экранах, влезает ли, свайп, наведение кнопок | ветка `shots-home` |
| Снимки до/после | `.github/page-shot.txt`: `<дата> <метка> /путь/ /путь2/` | экран + вся страница, вес, запросы, ошибки (ПК + A31) | ветка `shots-ab`, папка `<метка>/` |
| Скорость | `.github/speed.txt` | Lighthouse 5 страниц + причины медленности | `speed/latest.md` в main |

| Проба | `.github/probe.txt`: `<дата> <имя>` → `tools/probe/<имя>.js` | точечная проверка одной вещи | ветка `shots-ab`, `probe-<имя>/` |

Что запускать по теме:
- **сайт целиком / «всё»** → все строки таблицы.
- **языки** → рой (`swarm языки`), кликер (`языки`), языки, page-shot главных страниц языков (`/ua/ /de/ /fr/ /pt/ /es/ /it/`).
- **главная** → главная, page-shot `/en/`, рой, кликер, скорость.
- **кабинет / авторы** → авторы, site check, кликер.
- **оплата / корзина** → проба (`pay`), page-shot товара и корзины, рой.
- **скорость** → скорость, page-shot, рой (вес страниц).
- **ссылки / кнопки** → кликер, рой, фотограф.

Хостинг блокирует, если много роботов сразу (ответ 429 / капча «Сторінка захищена»): у каждого робота свои паузы и повторы, но при «всё» — рой и кликер сначала, фотограф и site check следующей волной (после окончания роя).

## 3. Пока работают
- Сказать владельцу одной строкой: какие роботы запущены и примерное время (рой ~50 мин, кликер 1,5–3 ч, языки ~30–60 мин).
- Ждать без опроса чаще 1 раза в 1–2 минуты (фоновая команда `until … ; do sleep 20; done`).

## 4. Итог владельцу (по-русски, коротко)
- По каждому роботу: сколько проверено, сколько находок (критично / важно / мелочь).
- Свести одинаковые находки разных роботов в одну.
- Отделить ложные тревоги (временный сбой сервера 503/429, пустой снимок = страница не загрузилась) от настоящих ошибок — проверить повторно curl/пробой.
- Список «что чиню сейчас» → чинить по правилу «скрины до и после» (CLAUDE.md, правило 9 SYNC.md), «готово» только после снимков «после».
