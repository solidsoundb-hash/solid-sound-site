Как делают другие (Steam, Spotify, многие магазины шаблонов): одна базовая цена + региональная скидка, которая включается сама по стране покупателя.

- Показ валют: США — $, Великобритания — £, остальные — €.
- Скидка считается по стране оплаты (карта / адрес), а не только по IP — чтобы не обходили через VPN.
- Нижний порог услуг: ни одна услуга не дешевле **€99**, кроме мастеринга и разбора трека.
- Наши данные по странам пока пустые (GA4 через Supermetrics: пробный период закончился, с 07.11 ~40 визитов, в основном Франция). После 1–2 месяцев рекламы пересмотреть группы.

## 4. Что ещё взять у конкурентов
- «Pay 50% now, the rest when you love it» (WMDM) — крупно на странице услуг.
- «100% copyright ownership + certificate» для гост-продакшна.
- Бесплатное демо мастеринга (Arefyev, ghost.pro).
- Оплата частями для гост-продакшна (EDM Ghost Producer — до 6 платежей).
- Постоянные клиенты сохраняют свои цены (Arefyev); у нас ещё 3 % бонусами.
- Акции −30…−50 % только по датам (Black Friday, Black Month), постоянная цена — средний сегмент.
