# Рейтинг и качество товаров (маркетплейс) — проект, 11.11.2026

Цель (владелец): на главную и в приоритетные места попадает только качественное. Авторов в начале владелец
вручную не контролирует, поэтому «плохой» товар не должен сам попасть на главную. Рейтинг мотивирует авторов
делать лучше (как у Amazon с книгами).

## Сигналы (за последние 90 дней, свежие весят больше)
| Сигнал | Откуда | Вес |
|---|---|---|
| Продажи | заказы WooCommerce (оплаченные) | ×10 |
| Конверсия: продажи / просмотры карточки | просмотры считаем анонимно | бонус до +30% |
| Оценки покупателей | отзывы WooCommerce (только купившие) | байесовское среднее, см. ниже |
| В корзину | анонимный счётчик | ×3 |
| В избранное | анонимный счётчик | ×2 |
| Прослушали демо до конца ≥ 30 с | анонимный счётчик | ×1 |
| Возвраты / жалобы | возвраты WooCommerce | штраф −20 за каждый |

Байесовское среднее оценки (честно для товаров с 1–2 отзывами):
`rating = (C × m + сумма_оценок) / (C + число_оценок)`, где m = 4.0 (среднее по сайту), C = 5.

Итоговый балл: `score = (продажи×10 + корзина×3 + избранное×2 + прослушивания) × (rating / 4) × бонус_конверсии − штрафы`.
Пересчёт раз в сутки (WP-Cron), хранится в мета товара `_ss_score`.

## Иерархия (уровни)
| Уровень | Условие | Где показывается |
|---|---|---|
| **Featured** (выбор владельца) | галочка владельца в админке | главная, первые места |
| **Best seller** | топ-10 по score + ≥ 3 продаж + rating ≥ 4.0 | главная «Best sellers», бейдж |
| **Trending** | быстрый рост score за 14 дней + rating ≥ 3.8 | главная (вкладка Trending), бейдж |
| **Catalog** | все одобренные товары | каталог, поиск |
| **New / on probation** | новый товар автора, < 3 продаж | только каталог и раздел «New», не на главной |
| **Hidden** | галочка владельца / rating < 3.0 при ≥ 5 отзывах / много возвратов | не показывается нигде, кроме прямой ссылки |

Товары владельца (Solid Sound) — доверенные: могут быть на главной без порога продаж.

## Для авторов (мотивация)
- В кабинете продавца: свой score, место в рейтинге, бейджи, подсказки «что улучшить» (обложка, демо, описание).
- Хорошие авторы чаще попадают на главную и в рассылки.

## Управление владельцем (админка)
- Галочки на товаре: «Featured», «Hide from home», «Hide everywhere».
- Страница «Ranking»: топ товаров с баллами, веса и пороги (можно менять).

## Приватность
Счётчики анонимные (без имён, IP не хранится, только агрегаты по дням). Ботов отсекаем.
