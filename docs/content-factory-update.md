# Контент-фабрика — изменения, которые нужно подтвердить на HOME-PC (13.11.2026)

Фабрика («Solid Sound — контент-фабрика недели», сб 11:52 Париж) привязана к компьютеру HOME-PC, поэтому её
настройки меняются только в приложении Claude на этом компьютере:

1. Приложение Claude → **Routines / Запланированные задачи** → «Solid Sound — контент-фабрика недели» → Edit.
2. **Модель**: Opus → **Sonnet** (экономия лимита в 2–3 раза; сценарист остаётся на Opus — это в тексте ниже).
3. **Текст задачи**: в начало, после первого абзаца, вставить:

```
ЭКОНОМИЯ ЛИМИТА (решение владельца 13.11.2026): ты (координатор) работаешь на Sonnet; Opus — только Сценарист; Аналитик, Копирайтер и выгрузка цифр — Sonnet/Haiku. Не повторяй работу, которую уже сделали роботы сайта.

Сначала прочитай сводку роботов сайта (обновляется по пятницам): новые товары, проблемы товаров, цены и новинки конкурентов, акции и поводы ближайших недель (например Black Friday), скорость сайта. Используй эти факты как «Основание: …» и не ищи их заново. Сводку владелец прикладывает в проект claude.ai как claude/robots-summary.md (копия файла docs/robots-summary.md из репозитория сайта).
```

4. Save.

Пока вы не подтвердили — фабрика работает по-старому (Opus, может упереться в лимит).
