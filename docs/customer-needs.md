# Боли и потребности клиентов — и как сайт на них отвечает (11.11.2026)

Источники: обзоры и статьи о найме инженеров сведения, форумы продюсеров, гайды по пост-продакшну
(часть — от самих сервисов, поэтому это ориентиры). Список ссылок — внизу.

## 1. Сведение и мастеринг (артисты, продюсеры)
| Боль | Что хочет клиент | Ответ Solid Sound |
|---|---|---|
| «Отдам трек — и не знаю, что с ним происходит» | видеть процесс | этапы проекта в кабинете (Received → In work → Revision → Delivered) |
| Правки — самое мучительное: «сделайте теплее» каждый понимает по-своему | точно объяснить, что не так | **комментарии по секундам на волне** + сравнение «до/после» |
| Боится переплатить за правки | понятные правила | «3 бесплатные правки», счётчик «осталось N из 3», окно 3 рабочих дня |
| Инженер пропадает, долго отвечает | быстрый ответ | чат «Ask the team», уведомления по email, срок в кабинете |
| Не понятно, умеет ли инженер мой жанр | примеры в моём жанре | «до/после» по жанрам (techno, house, vocal), отзывы |
| Боится, что «громко, но мёртво» | живой звук | примеры с динамикой, а не только громкость; объяснение в FAQ |
| Не знает, как подготовить проект | простая инструкция | шаги: Ableton (Collect All and Save) / мультитрек (−6 dB, без мастер-обработки), референс |
| Цена «по запросу» отпугивает | цена сразу | 3 пакета с ценами + калькулятор за 1 минуту |

## 2. Шаблоны Ableton, пресеты, сэмплы (продюсеры)
| Боль | Что хочет клиент | Ответ Solid Sound |
|---|---|---|
| Рынок завален слабыми паками | гарантия качества | **рейтинг качества**, на главной только хиты, отзывы покупателей |
| «Купил — а нужны плагины, которых нет» | работает сразу | метки «No external plugins / Stock plugins», версия Ableton на карточке |
| Боится нарушить права | royalty-free | «Royalty-free» + понятная лицензия на карточке |
| Хочет услышать до покупки | демо сразу | мгновенное прослушивание с карточки, волна |
| Шаблон «не учит», а только копирует | понять, как сделано | разбор/описание каналов, видео; связка «шаблон + сведение твоей версии» |
| Не хочет тратить деньги вслепую | попробовать | Free starter pack (+ вход через Google в 1 клик) |

## 3. Пост-продакшн звука (видео, реклама, YouTube, кино)
| Боль | Что хочет клиент | Ответ Solid Sound |
|---|---|---|
| Плохой звук с площадки: гул, ветер, эхо | «спасите диалоги» | услуга очистки/реставрации, примеры «до/после» видео |
| Долгие циклы правок, задержки | быстро и предсказуемо | срок в заявке, те же комментарии по таймкоду (на видео — по секунде ролика) |
| Не знает требований площадок (громкость для YouTube/TV/рекламы) | «чтобы приняли и звучало ровно» | «Delivery spec» в заявке: площадка → нужная громкость, версии 15/30/60 с |
| Цены непонятны и сильно разнятся | цена заранее | форма заявки + быстрая оценка, пакеты для типовых роликов |
| Редакторы видео «забывают» про звук | всё под ключ | sound design + Foley + музыка + финальный микс одним заказом |

## Главные выводы для сайта
1. **Прозрачность процесса** (этапы + комментарии по секундам) — закрывает №1 боль студийных клиентов. Это наш главный козырь.
2. **Цена и правила сразу** — пакеты, калькулятор, «3 бесплатные правки», сроки.
3. **Доверие** — рейтинг качества, отзывы, «до/после» по жанрам, royalty-free.
4. **Ноль трения** — вход через Google, Free pack в 1 клик, инструкция подготовки проекта.
5. **Пост-продакшн как отдельное направление** — свои примеры, спецификации площадок, форма заявки.
