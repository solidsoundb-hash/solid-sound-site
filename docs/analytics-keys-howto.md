# Как дать роботам доступ к Google Analytics и Meta (21.11.2026)

Ключи НЕ пишем в файлы (репозиторий публичный). Только в секреты GitHub:
GitHub → репозиторий solid-sound-site → Settings → Secrets and variables → Actions → New repository secret.

## 1. Google Analytics 4 (≈10 минут, бесплатно)
1. Откройте console.cloud.google.com → вверху «Выбрать проект» → «Новый проект», имя `solid-sound-stats`.
2. Меню → «API и сервисы» → «Библиотека» → найдите **Google Analytics Data API** → «Включить».
3. Меню → «IAM и администрирование» → «Сервисные аккаунты» → «Создать». Имя `stats-robot`, роли не нужны → «Готово».
4. Откройте созданный аккаунт → вкладка «Ключи» → «Добавить ключ» → «Создать» → JSON. Скачается файл.
5. Скопируйте адрес аккаунта (вида `stats-robot@solid-sound-stats.iam.gserviceaccount.com`).
6. analytics.google.com → Администратор (шестерёнка) → «Ресурс» → «Управление доступом» → «+» → вставьте этот адрес → роль **Читатель** → «Добавить».
7. В GitHub создайте секрет `GA4_KEY` — вставьте ВСЁ содержимое JSON-файла. Потом файл с компьютера удалите.
Номер ресурса (559451411) уже известен, его вводить не надо.

## 2. Meta (Facebook + Instagram + реклама) (≈15 минут, бесплатно)
1. business.facebook.com → «Настройки компании» → «Пользователи» → **«Системные пользователи»** → «Добавить», имя `stats-robot`, роль «Сотрудник».
2. «Добавить ресурсы»: страница Facebook Solid Sound, аккаунт Instagram, рекламный аккаунт — везде только **просмотр / аналитика**.
3. «Создать токен» → выберите приложение (если его нет: developers.facebook.com → «Мои приложения» → «Создать» → тип «Бизнес», затем вернуться) → срок «Никогда» → галочки: `read_insights`, `pages_read_engagement`, `instagram_basic`, `instagram_manage_insights`, `ads_read`.
4. Скопируйте токен → в GitHub секрет `META_TOKEN`.

## Что будет дальше
Когда секреты появятся, я сделаю робота: раз в неделю (понедельник) забирает визиты, страны, источники, конверсии из GA4 и охваты/клики/расходы из Meta и кладёт короткий отчёт в `reports/weekly/`. Ключи нигде не показываются, отключить — удалить секрет.
Мне ничего пересылать не нужно — просто скажите «ключи добавил».
