# Уроки (что узнали на практике) — читать перед работой, дописывать после

## Как работать с владельцем
- Владелец часто пишет «выложи / выкладывай по завершении» — это согласие выкладывать сразу после своей проверки.
  Каждое новое пожелание сразу записывать в `docs/owner-preferences.md` (с датой).
- Отвечать по-русски, коротко, без жаргона; показывать скриншоты через SendUserFile.
- Главная цель: самый удобный, понятный маркетплейс для клиентов, готовых платить. Каждое предложение сверять с ней.
- Не придумывать юридические условия (лицензия, «lifetime», «worldwide»): брать формулировки только из FAQ/License.

## Сайт и сеть
- Защита хостинга (adm.tools) после 3–5 быстрых заходов показывает «Сторінка захищена» (капча) или 429.
  Делать паузы 20–60 с между страницами, после блокировки ждать 2+ мин. Картинки тоже могут отвечать 429 — это не битая ссылка.
- Робот выкладки иногда долго стоит в очереди GitHub («Queued»). Новая выкладка содержит всё — старую можно отменить.
- С 11.11.2026 `gh run list / gh run view / gh run cancel` работают из облачной сессии — ход роботов видно напрямую.
- Каждая выкладка требует явного «выкладывай/ок» владельца на ЭТУ правку — иначе система безопасности её остановит; без него только коммит.
- Проверка ДО выкладки: открыть живую страницу в Playwright и подменить файлы сборки через `context.route`
  (`/(home-app|home-js|home-css|ss-global)\.[0-9a-f]{10}\.(js|css)/` → файлы из `build/assets/`). PHP так не проверить —
  для PHP: `php -l`, проверка совпадения имён функций, загрузка модуля с заглушками add_action/add_filter.

## Устройство (неочевидное)
- Два разных меню: главная — приложение (`src/home/app.template.html`, правки только через `patches.js`),
  остальные страницы — `src/ss-global.js` (шапка #ssg, нижняя панель, мобильное меню из того же списка NAV).
  Любую правку меню делать в ОБОИХ местах.
- Подсветка текущей страницы: адреса в меню без `/en/` — сравнивать без языкового префикса (normP в ss-global.js).
- Блоки главной имеют якоря: #shop #services #examples #reviews #dashboard #free; прокрутка — `ssGoTo` в home.js.
- Плеер, волны в каталогах, панель фильтров каталога (.sstb) живут в Theme Options → Custom HTML
  (`live/.../exports/theme-custom_html.php`). Код туда не добавлять — переопределять из плагина.
- Шапка темы (.l-header) больше не используется → всё, что считало её высоту (липкая панель фильтров), надо считать
  по #ssg (переменная `--ssg-h`).
- Подвал на всех страницах — `modules/footer.php` (старый подвал темы скрыт). Старые скрипты сами не дублируют ссылки,
  потому что видят `.ss-cc-open` и `[data-ss-legal]`.
- WooCommerce «Related products» перемешивает товары → выводим сами через шаблон `single-product/related.php` (`modules/similar.php`).
- Старые CSS-правила часто с `!important` и в нескольких @media — новые правила тоже ставить с `!important` и проверять ширину.
- Сетка с `1fr` на телефоне растягивается под самый широкий ряд кнопок → `minmax(0,1fr)` и `min-width:0`.
- Квадратную обложку не растягивать на широкую карточку (режется текст) — показывать целиком.

## Две сессии одновременно
- Владелец иногда работает во второй сессии Claude в том же репозитории. Перед каждой правкой: `git pull --rebase`,
  после правки сразу коммит и пуш. Номер выкладки в `.github/deploy.txt` — следующий после ПОСЛЕДНЕЙ строки файла.
- Во время заливки (шаг Upload, 3–7 минут) сайт может кратко падать, если новый `custom.php` уже на сервере, а новые
  модули ещё нет. Это проходит само; при постоянной ошибке робот откатывает. Предупреждать владельца заранее.

## Плеер без перезагрузки (12.11.2026)
- Переход без перезагрузки = `navigate()` в `src/theme/player.js`: подменяет `#page-content`, догружает новые скрипты.
  Всё, что вне `#page-content` (шапка темы `.l-header`, `#ssg`, подвал `.ssf`), остаётся — прятать/показывать CSS по
  классу body (`body.ss-newhome ...`), а НЕ перезагрузкой.
- Класс `ss-newhome` нельзя переносить на следующую страницу (keep в navigate его исключает).
- Главную при повторном заходе монтирует повторный запуск скрипта home-app (`#r<N>` в адресе).
- mod_pagespeed переименовывает файлы (`*.pagespeed.ce.*`, склейки `*.pagespeed.jc.*` + `eval(mod_pagespeed_...)`):
  подмена в тестах по regex без якорей работает; ошибки `mod_pagespeed_... is not defined` при переходе безвредны.
- Тест непрерывности: `addInitScript` перехватывает `HTMLMediaElement.prototype.play` (аудио не в DOM), метка `window.__mk`
  пропадает при перезагрузке; виновника перезагрузки видно через CDP `Network.requestWillBeSent` → `initiator.stack`.
- isCur('') = true (пустой адрес = текущая страница) — всегда проверять, что адрес не пустой.
