# Примеры пост-продакшна — разбор (21.11.2026)

## Главный пример — YouTube «THE WAY trailer 15s» (канал Solid-Sound, id zjc437O4ODc)
Владелец: «самый крутой пример, ставить первым». Робот `yt-probe` получил только название (YouTube не отдаёт файл роботам: 429 / «недоступно»).
Для кнопки до/после нужны два файла от владельца: готовый трейлер и версия «до» (черновой звук или без обработки) → `media-src/ab-video/the-way-before.mp4` / `the-way-after.mp4`.

## 5 звуковых пар (на главной во вкладке «Film · Ads · Video»)
| Пара | Что слышно | Цифры (до → после) | Вывод |
|---|---|---|---|
| Голос для эфира | голос плотный, ровный, «радийный» | громкость −21.8 → −11.7 LUFS; тихие места +15 дБ | оставить, сильный |
| Озвучка рекламы | голос громче, плотнее, ярче | −20.7 → −11.4 LUFS | оставить; половины по 30 с — укоротить до ~15 с |
| Выравнивание динамики | тихие фразы подтянуты | тихие места +8 дБ, громкие +12 дБ | оставить |
| Чистка записи | шум в паузах ниже | паузы −50 → −57 дБ | средний: в наушниках слышно, с телефона слабо — в конец списка |
| Декклип | почти без разницы | совпадение до/после 98 %, громкость одинаковая | убрать: на слух не отличить |

«После» громче «до» примерно на 10 LU (так и есть по факту обработки) — кнопка даёт скачок громкости, это нормально для демо.
