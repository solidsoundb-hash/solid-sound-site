## 4. Где искать 20 кандидатов (только публичные ник/ссылка, без почт и личных данных)

Кого ищем: продюсеры techno / melodic techno / tech house / house, которые **уже продают или раздают** шаблоны Ableton или
пресеты (Serum, Vital, Diva), активны последние 3 месяца, демо хорошего качества, без эксклюзива с большим магазином.

| Где | Как искать | Ожид. кандидатов |
|---|---|---|
| Gumroad, Payhip, Ko-fi Shop | поиск «Ableton template techno», «melodic techno Serum presets» | 6–8 |
| YouTube | «Ableton techno template», «how I made … (project file)» — каналы со ссылкой на продажу проекта | 3–4 |
| Instagram / TikTok | #abletontemplate, #technoproducer, #serumpresets — в профиле ссылка на магазин | 3–4 |
| Reddit r/ableton, r/Techno, r/edmproduction | посты «I made a free template / preset pack» | 2–3 |
| PresetShare, KVR Marketplace | авторы бесплатных паков с хорошими оценками — хотят монетизировать | 2–3 |
| SoundCloud / Bandcamp | в описании «template available» / «project file» | 1–2 |

Не берём: тех, кто продаёт чужие сэмплы/«ремейки» без прав; тех, кто эксклюзивен у крупного магазина (условия запрещают).
Список ведём в `docs/authors/candidates.md`: ник · ссылка · что продаёт · жанр · цена у них · почему подходит.
Связь — только через публичную форму/директ платформы и только после «ок» владельца.
