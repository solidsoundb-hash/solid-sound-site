# Конвейер контента: боль клиента → статья → вики → посты → видео (владелец, 28.11.2026)

Начинаем со статей. Главное — сначала найти **работающий формат** на цифрах, потом писать.

| Шаг | Кто | Что | Где результат |
|---|---|---|---|
| 1. Боли клиентов | Аналитик | Вопросы продюсеров (форумы, Stack Exchange, Reddit, комментарии YouTube, отзывы конкурентов, наши заявки/чат) → **топ-20 болей**: формулировка словами клиента, сколько раз встречалась, где, связанный наш товар/услуга | робот `pain-watch` (на базе client-scout + reviews) → `reports/analyst/pains.md` |
| 2. Контент конкурентов | Аналитик + Маркетолог | Блоги/статьи и YouTube 7 конкурентов + топ-авторы ниши: темы, формат (гайд, разбор трека, «5 ошибок», чек-лист, до/после), длина, картинки/аудио/видео внутри, дата, отклик (просмотры, комментарии, лайки — что публично) | робот `content-watch` → `reports/analyst/content.md` |
| 3. Работающий формат | Маркетолог | По шагам 1–2: какой формат и длина дают больше отклика; шаблон статьи (структура, заголовок, первый экран, примеры, аудио «до/после», CTA на товар) | `docs/marketing/article-format.md` |
| 4. План статей | Маркетолог + SEO | 10 тем = боль × спрос (запросы) × наш товар; у каждой — ключ, заголовок, какой товар/услугу ведёт | `docs/marketing/article-plan.md` |
| 5. Статья | Копирайтер (сценарист) | EN, по формату шага 3, факты проверены, без воды; ссылки на товары/услуги; картинки/аудио | вики `/en/wiki/` (выкладка сама: снимки ПК + A31, SEO-проверка) |
| 6. SEO и переводы | SEO + Копирайтер | title/description, разметка Article, внутренние ссылки; переводы DE/FR/ES после проверки EN | — |
| 7. Посты из статьи | Маркетолог | 3–5 постов/каруселей из каждой статьи (UTM) — черновиком; публикует владелец | `docs/marketing/` → строка в `docs/owner-decisions.md` |
| 8. Видео | Копирайтер (сценарист) + Контент-комбайн | Сценарий по кадрам из статьи → ролик; позже, когда формат статей подтверждён | `docs/content-auto/` |
| 9. Что сработало | Аналитик | Просмотры статей, время на странице, переходы в товар/корзину, отклик постов → обратно в шаг 3 (формат учится) | `reports/analyst/content-results.md` (раз в неделю) |

Правила: только публичные данные, без имён людей в репо (суть вопроса); чужие тексты не копируем; цифры — с источником.
Первая проверка формата: 3 статьи → 2 недели цифр → решаем, масштабировать ли.
