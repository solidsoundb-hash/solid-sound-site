# Фокус команды: результат, а не работа ради работы (владелец, 28.11.2026)

Владелец: «следи, кто что делает, и оптимизируй работу так, чтобы она приносила результат… у нас не работа ради работы».

## Где мы (27.11)
- Людей на сайте: ~15–30 в день. Источники почти все «direct», из Google — единицы.
- Воронка за 7 дней: товар 31 → корзина 6 → оформление 1 → **заказов 0**.
- **Оплата не включена** → продажа невозможна в принципе. Это узкое место №1.

## Цели по ступеням (следующая открывается, когда выполнена предыдущая)
1. **Первая продажа.** Оплата работает, путь «товар → оплата → скачивание» проверен роботом `buy-night`. Держит: решение владельца №1.
2. **Трафик 100 людей в день** из поиска, постов и YouTube. Делают: Копирайтер (статьи), SEO, Маркетолог (посты, YouTube).
3. **Конверсия ≥ 1 %** товар → покупка. Делают: Дизайнер, Тестировщик (персоны), Продажи, Аналитик.
4. **Авторы** (вторая сторона маркетплейса) — после первых продаж: с нулём продаж авторов не позвать.

## Проверка каждой задачи перед началом
«Какую цифру ступени это двигает и когда мы это увидим?» Нет ответа → не делать.
Отчёт, который никто не читает и по которому ничего не делают, — выключить или реже.
Робот (GitHub Actions) бесплатен; дорого — время Claude (общий лимит). Поэтому: роботы-сторожа сайта работают часто, смены Claude — только где есть дело.
